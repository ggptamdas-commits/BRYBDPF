# BRYBDPF — স্মার্ট ব্লাড ডোনেশন ও মিলি-সেকেন্ড ডোনার সার্চ প্ল্যাটফর্ম 🩸

BRYBDPF হলো ক্লাউডফায়ার এজ আর্কিটেকচার এবং D1 ডাটাবেজ দ্বারা চালিত একটি অতি-দ্রুত এবং আধুনিক স্মার্ট ব্লাড ডোনেশন প্ল্যাটফর্ম। এর মূল লক্ষ্য হলো রক্তদাতা সংগ্রহ করা, মিলি-সেকেন্ডের মধ্যে কাঙ্ক্ষিত ব্লাড গ্রুপের ডোনার খুঁজে বের করা এবং তাৎক্ষণিকভাবে টেলিগ্রাম বটের মাধ্যমে সংশ্লিষ্ট অ্যাডমিনদের অ্যালার্ট পাঠানো।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **⚡ মিলি-সেকেন্ডে ডোনার সার্চ (Millisecond Edge Search):**
   - ক্লাউডফায়ার D1 ডাটাবেজ এবং ইনডেক্সড কোয়েরির মাধ্যমে মাত্র কয়েক মিলি-সেকেন্ডে কাঙ্ক্ষিত রক্তের গ্রুপ ও জেলার ডোনারদের তালিকা চলে আসে।
   - রেসপন্স টাইমের লাইভ কাউন্টার (e.g. `⚡ রেসপন্স টাইম: ৪ ms`)।

2. **🩸 আধুনিক ও মিনিমাল ব্লাড থিম ডিজাইন (Modern Minimal Blood Theme):**
   - গভীর রক্তিম লাল (`Crimson Red`), স্লিপ হোয়াইট ও স্লট এলিমেন্টের কম্বিনেশন।
   - ১০০% মোবাইল ফ্রেন্ডলি ও রেসপনসিভ (UI/UX Pro Max স্ট্যান্ডার্ড, ৪৪x৪৪px মিনিমাম টাচ টার্গেট, অ্যাক্সেসিবল SVG আইকন)।

3. **🔒 নিরাপদ অ্যাডমিন প্যানেল (Zero Hardcoded Credentials & Brute-force Protected):**
   - কোডের কোথাও কোনো অ্যাডমিন ইমেইল বা পাসওয়ার্ড হার্ডকোড করা নেই।
   - প্রথমবারের জন্য ইনিশিয়াল সেটআপ উইজার্ড (`/admin`), যেখানে অ্যাডমিন নিজস্ব ইমেইল ও মাস্টার পাসওয়ার্ড সেট করেন।
   - পাসওয়ার্ডগুলো PBKDF2 (SHA-256 + 100,000 iterations) ও ইউনিক সল্ট (Salt) দিয়ে ক্রিপ্টোগ্রাফিক্যালি হ্যাশ হয়ে সংরক্ষিত হয়।
   - **লগইন লিমিট ও ব্রুট-ফোর্স প্রটেকশন:** কোনো আইপি থেকে টানা ৫ বার ভুল ইমেইল বা পাসওয়ার্ড দিলে পরবর্তী ১৫ মিনিটের জন্য উক্ত আইপি সাময়িকভাবে লক হয়ে যায়।
   - নিরাপদ ক্রিপ্টোগ্রাফিক সেশন টোকেন অথেন্টিকেশন।

4. **🚑 ব্লাড রিকোয়েস্ট ও ডুয়াল সম্মতি (Emergency Request & Auto-Donor Integration):**
   - হোমপেজে সরাসরি জরুরি ব্লাড রিকোয়েস্ট ফর্ম।
   - রিকোয়েস্ট পাঠানোর আগে দুটি বাধ্যতামূলক অঙ্গীকারনামায় টিক দিতে হয়:
     - `১. ভবিষ্যতে কারো রক্ত লাগলে রক্ত দেয়ার চেষ্টা করবো`
     - `২. আমার সকল তথ্য ডুনার লিষ্টে সেইভ রাখলে আমার কোন সমস্যা নেই`
   - রিকোয়েস্টকারী পূর্বে ডোনার হিসেবে নিবন্ধিত না থাকলে স্বয়ংক্রিয়ভাবে তার তথ্যও ডোনার তালিকায় সংরক্ষিত হয়।
   - **রেট লিমিটিং:** বাল্ক রিকোয়েস্ট ঠেকাতে গাণিতিক রোবট ক্যাপচা (Anti-Bot Captcha) এবং একই নম্বর দিয়ে ২৪ ঘণ্টার মধ্যে একাধিকবার রিকোয়েস্ট ব্লক করার নিরাপত্তা ফিল্টার।

5. **🤖 তাৎক্ষণিক টেলিগ্রাম বট নোটিফিকেশন ও ১-ক্লিক হোয়াটসঅ্যাপ শেয়ার:**
   - যে কোনো জরুরি রিকোয়েস্ট তৈরি হওয়ার সাথে সাথে নির্ধারিত অ্যাডমিনদের টেলিগ্রাম ইউজার আইডিতে (UIDs) বিস্তারিত বার্তা চলে যায়।
   - বার্তার সাথে সাথে উক্ত রক্তের গ্রুপের শীর্ষ ২০ জন ম্যাচিং ডোনারের নাম, জেলা, ফোন নম্বর, কল বাটন এবং হোয়াটসঅ্যাপ লিংক সংযুক্ত থাকে।
   - অ্যাডমিন চাইলে এক ক্লিকেই পুরো ডোনার তালিকাটি প্রি-ফরম্যাটেড মেসেজ আকারে রিকোয়েস্টকারীর হোয়াটসঅ্যাপ নম্বরে ফরওয়ার্ড করতে পারেন।

6. **🚫 ডুপ্লিকেট রোধ ফিল্টার:**
   - একই মোবাইল নম্বর দিয়ে একাধিকবার রক্তদাতা হিসেবে রেজিস্ট্রেশন করা যাবে না।
   - একই নম্বর দিয়ে ২৪ ঘণ্টার ভেতর একাধিকবার ব্লাড রিকোয়েস্ট করা যাবে না।

## 🗄️ ডাটাবেজ স্কিমা (Cloudflare D1)

- **`donors`**: রক্তদাতাদের নাম, রক্তের গ্রুপ, ফোন নম্বর (UNIQUE), জেলা, উপজেলা/এলাকা, বয়স, লিঙ্গ, শেষ রক্তদানের তারিখ, মোট রক্তদান, সক্রিয় অবস্থা (`is_available`), সম্মতি স্ট্যাটাস।
- **`blood_requests`**: রোগীর নাম, রক্তের গ্রুপ, ব্যাগ সংখ্যা, হাসপাতালের নাম, জেলা, এলাকা, যোগাযোগের নম্বর, সময়সীমা, স্ট্যাটাস (`Pending`, `Matched`, `Fulfilled`, `Closed`)।
- **`admin_settings`**: অ্যাডমিন হ্যাশড ক্রেডেনশিয়ালস, টেলিগ্রাম বট টোকেন ও অ্যাডমিন টেলিগ্রাম আইডি।
- **`login_attempts`**: আইপি ভিত্তিক লগইন ট্র্যাকিং এবং ব্রুট-ফোর্স রোধের লগ।
- **`sessions`**: অ্যাডমিন সেশন টোকেন ও মেয়াদোত্তীর্ণের তারিখ।

## 🚀 ক্লাউডফায়ার ডেপ্লয়মেন্ট নির্দেশিকা (Cloudflare Deployment Guide)

### ১. ডিপোজিটরি ক্লোন:
```bash
git clone https://github.com/ggptamdas-commits/BRYBDPF.git
cd BRYBDPF
```

### ২. ক্লাউডফায়ার D1 ডাটাবেজ তৈরি ও স্কিমা প্রয়োগ:
```bash
npx wrangler d1 create brybdpf-db
npx wrangler d1 execute brybdpf-db --file=schema.sql
```

### ৩. ক্লাউডফায়ার ওয়ার্কার ডেপ্লয়:
```bash
npx wrangler deploy
```

## ⚙️ অ্যাডমিন সেটআপ ও টেলিগ্রাম কনফিগারেশন

১. ব্রাউজারে সাইটের `/admin` লিংকে প্রবেশ করুন।
২. প্রথমবার প্রবেশ করলে স্বয়ংক্রিয়ভাবে প্রাথমিক সেটআপ উইজার্ড প্রদর্শিত হবে।
৩. আপনার নিজস্ব অ্যাডমিন ইমেইল, শক্তিশালী পাসওয়ার্ড এবং আপনার টেলিগ্রাম বট টোকেন ও টেলিগ্রাম ইউজার আইডি (UID) প্রবেশ করিয়ে সাবমিট করুন।
৪. পরবর্তীতে অ্যাডমিন প্যানেল থেকেই ডোনার সক্রিয়/নিষ্ক্রিয় করা, রিকোয়েস্ট ম্যানেজ করা এবং ১-ক্লিকে রিকোয়েস্টকারীকে ডোনার তালিকা পাঠানো যাবে।
